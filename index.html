操作說明

新增與編輯

  • ＋ 新增商品：填商品名稱、廠家、價格、數量、預定取貨年月。快捷鍵 Ctrl+N。
  • 商品圖片：可以上傳檔案（會自動壓縮存在本機），或直接貼商品頁的圖片網址。用網址資料量會小很多。
  • 取貨時間未定：年月留「未定」即可，之後再回來補。
  • 付款狀態：未付款／已付訂金／已付清。選訂金會多出金額欄，下面即時算出尾款。
  • 已領貨一律視為已付清，這時付款欄會鎖住；要改請先把領貨狀態改回未領貨。

上方清單（未領貨）

  • 標記已領：商品會離開這裡，移到下方的已取貨紀錄，付款狀態自動變成已付清。
  • 月台：最上面那排月份卡片，點一下只看該月，再點一次取消。紅色上緣代表有逾期未領。
  • 月份面板：點標題可以收合／展開，狀態會記住。旁邊有「全部展開／收合」。
  • 搜尋：商品名稱、廠家、備註都找得到，上下兩區同時生效。按 Esc 清空。

調整順序

  • ▲▼ 按鈕：一次移動一格，最穩定的方式，手機上也好按。
  • 拖曳把手：每列最左邊的六點圖示，按住拖到想要的位置。
  • 拖到別的月份：商品的取貨月份會跟著改成那一個月。
  • 已取貨紀錄拖到別的年份：取貨日的年份會跟著改（月日保留）。日期沒填完整的會退回原位。
  • 排序要選「取貨時間」、已取貨那區要選「手動排序」，才能調位置；其他排序是系統算出來的，手動位置會被蓋掉。

圖表與提醒

  • 月度支出：長條圖顯示所選年份每個月的金額，綠色是已付、橘色是待付。點某一根只看那個月。
  • 逾期未領與本月要取貨會在上方跳出提醒卡，點一下直接篩到那些商品。
  • 點商品縮圖可以看大圖，鍵盤按 Enter 也可以。

金額與預算

  • 上方四張卡：花費總額、未付款總額、年度花費、已付款總額。
  • 年份可以自己選：第三張卡標題上的下拉，選得到資料裡出現過的每一年，也可以看「全部年份」。
  • 我的預算在進度條那一區，直接點數字就能改。旁邊可以切計算基準：全部商品／只算未領貨／只算待付。

刪除與復原

  • 刪除是軟刪除，會先進回收桶。刪除後的提示訊息上有「復原」可以按。
  • Ctrl+Z 復原最近一次刪除。
  • 右上角回收桶可以逐筆復原或永久刪除，最多保留 50 筆。

備份與匯出入

  • 自動備份：每天一份，開頁面或切回分頁時檢查，內容沒變不會重複存。
  • 立即備份：隨時手動存一份。匯入前、還原前也都會自動備一份。
  • 匯出 JSON：完整資料含圖片，換裝置或換瀏覽器就靠這個。
  • 匯出 Excel：含統計列，方便對帳，但不含圖片檔。
  • 匯入檔案：JSON、Excel、CSV 都能讀，欄位標題中英文都認得。可選覆蓋或加到現有清單。
  • 雲端備份：連上 Drive 後每週會自動把一份備份存到雲端，最多留 3 份。清掉瀏覽器資料也救得回來。
  • 圖片瘦身：把已經存進來的圖片重新壓小，同步會變快，畫面看不出差別。

Google Drive 同步

尚未連線

這個頁面不是從網址開啟的（目前來源：）。直接點開下載的 HTML 檔案時， 瀏覽器的來源是 file://，Google 一律拒絕這種來源的授權，最後會出現「錯誤 400: invalid_request」。 請改從你放在 GitHub Pages 之類靜態空間的網址開啟這個頁面。本機這份已經輸入的資料， 可以先用「匯出 JSON」帶走，再到網站版用「匯入檔案」讀回來。
已經填好這個 app 的用戶端 ID，通常不用動。要換成別組再自行覆蓋。

第一次設定：五個步驟
  1. 先把這個 HTML 放上靜態空間拿到 https 網址（GitHub Pages 免費且夠用）。
  2. 到 Google Cloud Console 建一個專案，在「API 和服務」裡啟用 Google Drive API。
  3. 設定「OAuth 同意畫面」，使用者類型選「外部」，並把自己的 Google 帳號加進測試使用者。 不用送審，測試模式自己用就夠。
  4. 建立憑證 → OAuth 用戶端 ID → 類型選網頁應用程式，在「已授權的 JavaScript 來源」填入 （就是你放這個檔案的網址開頭，不含路徑）。
  5. 把產生的用戶端 ID 貼到上面，按「連線並同步」。其他裝置打開同一個網址、貼上同一組 ID、 登入同一個 Google 帳號，就會拿到同一份資料。

資料會存成你雲端硬碟裡的一個檔案 preorder-list-data.json， 這個 app 只拿得到它自己建立的檔案，碰不到你硬碟裡的其他東西。
