尚未連線

這個頁面不是用 https 開啟的（現在是 ）。Google 登入只接受 https 或 localhost， 請先把這個檔案放到 GitHub Pages、Cloudflare Pages 或 Netlify 之類的靜態空間再來設定。
在 Google Cloud Console 建立的「網頁應用程式」用戶端 ID。只存在這台裝置，不會傳到任何地方。

第一次設定：五個步驟
  1. 先把這個 HTML 放上靜態空間拿到 https 網址（GitHub Pages 免費且夠用）。
  2. 到 Google Cloud Console 建一個專案，在「API 和服務」裡啟用 Google Drive API。
  3. 設定「OAuth 同意畫面」，使用者類型選「外部」，並把自己的 Google 帳號加進測試使用者。 不用送審，測試模式自己用就夠。
  4. 建立憑證 → OAuth 用戶端 ID → 類型選網頁應用程式，在「已授權的 JavaScript 來源」填入 （就是你放這個檔案的網址開頭，不含路徑）。
  5. 把產生的用戶端 ID 貼到上面，按「連線並同步」。其他裝置打開同一個網址、貼上同一組 ID、 登入同一個 Google 帳號，就會拿到同一份資料。

資料會存成你雲端硬碟裡的一個檔案 preorder-list-data.json， 這個 app 只拿得到它自己建立的檔案，碰不到你硬碟裡的其他東西。
